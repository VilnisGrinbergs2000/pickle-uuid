# Changelog

## 1.0.0 - 2026-11-26

- Initial release.
- `Uuid` with canonical, compact, `urn:uuid:`, and braced parsing.
- Version 4 generation from the operating system CSPRNG.
- Version 7 generation with a Unix millisecond timestamp and 74 random bits.
- Version and variant extraction, byte-order comparison, nil and max values.
